# Backlog

TL;DR:
- Candidate work, not committed work.
- Cards here are ideas pulled from research, competitor reviews, and field notes.
- Nothing here is scheduled until it moves into a numbered phase folder (`01_mvp/`, `02_*/`, ...).

#aop #tasks #backlog

-----

The backlog is where ideas wait. It is not a queue, not a wishlist, not a roadmap.

Each card here should answer: what is the idea, where did it come from, and what fit does it have with the current northstar. If a card cannot say where it came from, it belongs in `research/` first.

When an item gets picked up, move the card into the active phase folder and update its shape to a real build card (`tasks/_extend.md`).

Items that fail the northstar test should still get written down. The point is to remember why we said no.
