# Andon

TL;DR: If the work drifts from the project promise or the evidence cannot be reconciled, stop and name it.

#practice #andon #quality

-----

Andon means stop the line when continuing would compound a defect.

For this project, pull andon when:

- A task wants to publish material with unclear permission.
- A line is being styled as verified when it is only inferred.
- Parcel acreage, official acreage, and drawn boundary do not reconcile.
- The map is becoming a contribution app before the validation loop proves itself.
- A source looks useful but its license forbids the intended export.

The move is not drama. It is just the work becoming honest.

## How to write it down

```md
## Andon

**Pulled:** One-line issue.

**Source:** Path or source name.

**What's happening:** The conflict in plain language.

**Options:**
- **Verify:** What evidence would settle it.
- **Revise:** What changes if the current assumption is wrong.
- **Defer:** What remains blocked until this is answered.
```

Do not silently choose one source and bury the disagreement in the geometry.
