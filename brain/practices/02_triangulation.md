# Triangulation

TL;DR:
- Treat every map fact as a claim until independent evidence supports it.
- Agreement between sources is useful, not final. Shared wrong assumptions still happen.
- Reality is the arbiter: field checks, official confirmation, current imagery, and permission.

#practice #triangulation #evidence #sources

-----

The AOP map is an information problem.

One source can be wrong. Two sources can share the same stale data. Three independent claims, checked against reality, are where confidence starts to mean something.

## The triangle

For this project, triangulate across:

- **Authoritative records:** parcels, USGS, TDOT/TNMap, official AOP material.
- **Observed artifacts:** imagery, hillshade, GPX, board marks, photos, app exports.
- **Human reality:** AOP staff, riders, field validation, current closures, permissions.

When the three disagree, do not average them. Name the disagreement.

## What disagreement means

If parcels disagree with official acreage, the boundary is not settled.

If app trails disagree with imagery, the trail is a candidate until checked.

If a source looks accurate but permission is unclear, it stays inspection-only.

If field notes disagree with the printed map, the printed map may be stale.

The disagreement is useful. It tells the project what to verify next.

## Map rule

Confidence is not vibes.

Every promoted feature should be able to point at the sources that support it and the evidence that would demote it.
