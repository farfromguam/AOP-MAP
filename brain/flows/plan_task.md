# Plan Task Flow

TL;DR: Turn a request into a task card that can be executed without re-planning.

#flow #planning #tasks

-----

Planning is stage 1. Do not execute the work in the same pass unless the user explicitly says to continue and the work is small.

## Work

Restate the request in plain language.

Check `northstar/` for locked promises.

Check `research/` for source facts and caveats.

Apply AAF. If the decision is already settled, say so. If not, write the suggested answer first.

Define scope and out of scope.

Write acceptance criteria.

Write verification steps.

Name any open questions and what would close them.

Save or update the task card in `tasks/`.

## Handoff

A card is ready for `work_task` when it has:

- source links
- scope
- acceptance criteria
- verification
- open questions or explicit "none"
- execution order when sequencing matters

If those are missing, keep planning.
