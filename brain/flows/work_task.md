# Work Task Flow

TL;DR: Execute a prepared task card, then record what changed.

#flow #execution #tasks

-----

Work is stage 2. It starts from a card, not from vibes.

## Work

Read the card.

Confirm scope, acceptance, and verification are present.

Execute the planned steps.

If the plan is wrong, stop and write the delta instead of silently widening scope.

Run the verification steps.

Record what landed, what diverged, and what remains open.

Update related docs when the work changes a promise, source fact, or reusable method.

## Output

The card should end with a short implementation note:

- what changed
- verification run
- unresolved gaps
- follow-up needed

If verification fails, the output is not "mostly done." It is a new planning delta.
