# User writing style

TL;DR: For repo writing, front-load the gist. Put depth below the divider.

#ai_rules #voice #writing

-----

For task cards, audits, research notes, and brain docs:

- TLDR or goal up top.
- Ease into the problem next.
- Put deep scope, code blocks, source tables, and contested decisions below `-----`.

The user's own lead-in can be the TLDR. Do not paraphrase it just to sound official.
