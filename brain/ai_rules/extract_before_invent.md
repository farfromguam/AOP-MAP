# Extract before invent

TL;DR: Before inventing a term, workflow, schema, or answer, check the brain first.

#ai_rules #aaf #extract

-----

Default move: extract, do not invent.

For AOP work, check:

- `northstar/` for locked promises.
- `research/` for source facts.
- `tasks/` for staged direction.
- `practices/` for the method.
- `search_map.md` for routing.

If the brain answers the question, cite it and move.

If the brain conflicts with reality, pull andon. Do not pick one source and override the rest.
