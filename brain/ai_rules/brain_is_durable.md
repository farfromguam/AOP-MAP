# Brain is durable

TL;DR: If a fact, rule, source note, or working decision matters next time, put it in this brain.

#ai_rules #durability #brain

-----

The brain is the source of truth.

Memory is for session ephemera only. "User is testing a QGIS export right now" can be transient. "Official AOP map permission is unclear" belongs in `research/` or `northstar/`.

How to place durable material:

- project promises: `northstar/`
- source facts: `research/`
- work plans: `tasks/`
- reusable process: `flows/` or `practices/`
- assistant collaboration rules: `ai_rules/`

Harness adapters (Claude Code skills, hooks, commands) are NOT a place for durable content — they are thin pointers into this brain. See `harness_adapters_are_thin.md`.
