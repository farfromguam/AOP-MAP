# Preserve card directives

TL;DR: When editing a task card, keep the user's original directives visible.

#ai_rules #cards #directives

-----

Do not delete user-written card items just because analysis changes the recommendation.

Light polish is fine. Removing the record is not.

If a directive is wrong, stale, risky, or already answered, put the analysis below the divider and show the path forward. The card is both a work plan and a record of the user's thinking.
