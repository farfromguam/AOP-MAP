# Move slowly on core work

TL;DR: Core project decisions get one careful pass at a time, with verification beside the work.

#ai_rules #pacing #quality

-----

For core AOP map work, do not batch big changes.

One card at a time. Verify as you go. Stop when the next step depends on field truth, source permission, or a user call.

Fast drafting is fine. Fast locking is not.
