-----

Research docs answer "what do we know, and where did it come from?"

For AOP mapping, research should stay separable from task planning. Source facts, caveats, links, and open evidence gaps go here. Build sequencing goes in `tasks/`.

When a source changes, update the research doc first. Then update the card or northstar only if the change affects direction.
