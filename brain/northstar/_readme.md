Northstar docs answer "what must stay true?" They sit above task cards.

For this project, the main promises are simple:

- The map is evidence-led.
- Source confidence and permission stay visible.
- Print and web come from the same data spine.
- Field validation feeds observations first, not silent overwrites.
- The validation loop is the way evidence becomes map truth.

If a task card wants to hide provenance, publish uncertain data as verified, or build intake before the validation loop proves itself, this branch is the thing to cite.
