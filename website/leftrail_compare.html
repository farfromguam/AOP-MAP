Left rail — element variant review

New baseline: the higher-contrast palette (former theme variant #12) is now the master, pinned at the top. Below it, four element-focused exploration categories — three flavors each. Every variant restyles ONLY its target element; the rest of the chrome stays at the baseline so the comparison is meaningful. Categories: buttons, gates open (countdown), live + next (calendar happening / upcoming_next rows), past + future (calendar past / default rows). Click any control inside a preview to try it.

Next-event indicator — replaces "Gates open" countdown

Replaces today's static "Gates open in 3d 14h" with a dynamic next-event signal. Two display modes per variant: FAR (next event > 1 hour out) = inline ticker in the calendar header; CLOSE (next event ≤ 1 hour) = the standalone ticker disappears and the upcoming_next row carries a countdown badge. Each preview below shows BOTH modes stacked so you can compare the transition. Iframes are taller for this reason.

N1Next — minimal

QuietFar: single-line slim ticker, no fill, 1px bottom rule, tabular time-to-go. Close: small outlined rust countdown chip ("in 47m") replaces the NEXT pill.
