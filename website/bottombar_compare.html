Bottom bar — collapse two stacked bars into one horizontal row

One direction, four minimal takes. On the installed phone PWA the bottom of the screen stacks two full-width bars: the collapsed AOP edit panel header (with ⧉ export + ▸ expand) and the N publish features loaded status pill. These mockups fold both into one horizontal row, freeing the band of map they ate. Each renders inside a phone frame over a map-toned background with the real palette tokens and glyphs from index.html, so the comparison is honest. Pick the attributes you want from each column — status treatment, edit label, divider, footprint. (Live count is whatever publish.geojson holds; it is 5 today.)
