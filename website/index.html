Layer notes
Terrain: use the 3D button with any preset. AWS Terrain Tiles, derived from USGS 3DEP. Two-finger drag tilts; right-click drag rotates (pinch zooms). Satellite tiles served by TDOT/TNMap — inspection use only, not for redistribution. USDA NAIP traces are raw candidates. Keep them out of publish until source, confidence, and field/imagery review are attached. Contours: USGS 3DEP 1 m lidar DEM. Detail tiers by zoom — 50 ft index lines when zoomed out, all 25 ft index lines at mid-zoom, fine 5 ft lines when zoomed in. Cemeteries: TN Comptroller Marion County parcels. Ellis Cemetery is the inholding inside the AOP boundary — the gap in the park polygon. Buildings: FEMA USA Structures footprints over the 9-patch. Raw reference context; verify against imagery before treating as park facilities. Activity hotspots: time-weighted from first-party timestamped GPX. Longer dwell in one cell draws hotter; raw evidence only. Simulated Saturday activity: deterministic synthetic pavilion-start tracks, crawl attempts, dwell, and extracted hotspots for testing the hotspot pipeline. Not field evidence. Event schedule: proposed RC event sessions from website/data/aop_event_schedule.json. Schedule rows use location tags such as #pavilion; tag a real feature with that tag in the edit panel (or set coordinates once under locations) instead of repeating coordinates. Visitor context callouts: support-town planning notes from AOP, RiderPlanet, and Marion County Tourism. Times are approximate; check live routing and hours. SFWDA raster is © Adventure Off Road Park (via SFWDA) — internal/inspection only. Drag the 4 corner handles in Edit mode to pixel-align against OSM tracks, then Copy alignment JSON and paste it into website/data/sfwda_raster_alignment.json.
