Edit dock · one interface, every type

Every editable thing on the right opens the same dock. The shell never changes — header → tabs (Identify · Edit · Display · Source) → tab body. The Edit tab holds both per-feature operations (Move / Vertices / Duplicate / Delete / Lock / Copy) and the layer's paint (opacity / color / width) — so feature edits and layer settings share one home, no separate drawer. Read-only layers show the same shell with inputs locked.
