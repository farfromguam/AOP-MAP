Right sidebar — one global tabbed edit panel

One direction, four placements. The base is the current reworked sidebar (right_panel.html / panel-embed.css): the real Source · Derived · External · Map editor · User submitted provenance sections, the node/item tree, the rust-on-cream palette. Onto it goes one global tabbed edit panel (Identify · Edit · Display · Source, the confirmed 4-tab contract) that replaces today's per-row inline editors. Each take differs only in where that one panel lives and how its tabs are styled. Width-when-scrolling is fixed in all four: the tree reserves the scrollbar gutter (scrollbar-gutter:stable) so it never reflows or clips when the scrollbar comes and goes, and the edit panel sits outside the scroll region so it always spans the full panel width.   • Placement — bottom dock (V1), full takeover (V2), fixed split (V3), floating sheet (V4). This is the main fork.
  • Idle behavior — editor vanishes when nothing is selected (V1/V2, cleanest tree) vs. a persistent placeholder so the layout never jumps (V3) vs. tap-scrim-to-dismiss (V4).
  • Tab chrome — underline strip (V1/V2/V4) vs. segmented pills (V3). Independent of placement — mix freely.
  • Tab set — full 4 tabs Identify · Edit · Display · Source (V1–V3) vs. 3 tabs with Display's two toggles folded into Edit (V4). Fewer tabs = shorter common path; 4 tabs = cleaner separation.
  • Width-when-scrolling — every take uses scrollbar-gutter:stable on the scroll regions and keeps the edit panel out of the scrolling box, so the gutter is reserved and nothing reflows or clips. Long labels ellipsis instead of widening the panel.
  • Header — type pill + feature name + Fly-to + close/back, identical across all four; swap glyphs as you like.
