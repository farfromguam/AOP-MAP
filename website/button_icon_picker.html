1 · Pill container styles

Same icon set throughout so you can compare just the container treatment. Active state = the chip highlighted in each pill.

A · Segmented
(rounded, fused)

A — Most "iOS-like." Reads clearly as two grouped controls and a separate modifier. Active state pops because the divider lines vanish on the filled chip.

B · Separated chips
(matches current site)

B — Lowest visual change vs. today; each chip already lives in its own rounded rect. Group container makes the pill feel less "fused" than A.

C · Outlined pill
(rust active)

C — Lighter weight; the map shows through. Uses rust for active so the choice doesn't compete with the moss already used elsewhere in the panel.

D · Solid brown
(inverted)

D — Heaviest; matches the hot-buttons' brown chrome. Pulls visual weight away from the calendar / hot-control beneath, which may be wrong since this bar shouldn't dominate.

E · Underline tabs
(no container)

E — Quietest. The buttons borrow the existing left-tab visual language (Events / Park / About). Risk: state is harder to read at a glance because there's no chip.
