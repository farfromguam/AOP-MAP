Add any type to any layer — where the + lives

One change, four placements. Today a lone + sits on the layer row and only adds that layer's native geometry. The change: move it into the inline edit area that opens under a selected layer, right of the eye and lock, and split it into + POI · + Line · + Polygon so any geometry can be added to any layer. Each take shows the same selected layer — Park buildings, a Polygon layer — whose edit area now also offers a point and a line. Base is the current panel (right_panel.html / js/panel.js): maturity-led tree, real provenance sections, rust-on-cream palette. The takes differ only in how compact vs. explicit the three add buttons are.

What's the same in all four

  • The move — the + is gone from the layer row; it now lives in the inline edit area beside the eye and lock, exactly where the per-layer controls already are.
  • Any type, any layer — every editable layer offers + POI / + Line / + Polygon, not just its native geometry. The demo selects a Polygon layer (Park buildings) to make that land: you can drop a point or a line into it.
  • Add isn't blocked by the lock — the lock protects existing features; a brand-new draw is always editable, so the add buttons stay live even on a locked/curated layer (matches today's create behaviour).
  • Flow after click — pressing a type enters place-mode (the existing rust "click the map to place" hint), same as the old single +.
