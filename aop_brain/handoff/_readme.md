# Handoff

TL;DR: Session-specific context and handoff notes for the current AOP MVP work.

This folder is for the working context that should travel to the next session, not for durable northstar promises.

Use it when:
- a later session needs to pick up where the current one left off
- a validation loop is being tested and the next run needs the exact test plan
- the current session has notes that are useful but not yet project policy

Do not put locked promises or final project rules here. Those belong in `northstar/`.
